# Kiro Configuration

This directory contains Kiro-specific configuration and settings for The Referee project.

## Contents

- `steering/` - Contains steering files for guided development workflows
- `settings/` - Project-specific settings and configurations

## About The Referee

The Referee is a comparison tool that helps developers make informed decisions by analyzing trade-offs across multiple options and criteria. It's designed to provide balanced analysis rather than simple recommendations.

## Development Notes

- Built with Node.js and ES modules
- Uses Commander.js for CLI interface
- Chalk for colorized output
- Inquirer for interactive prompts
- Modular comparator system for different domains
